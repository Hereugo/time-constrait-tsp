# Contribution

Special thanks to creators of the scripts in the `generators` directory, which were used to generate the instances for this project.

## Usage

The `generate.sh` script is a convenient wrapper around Rudy, allowing you to generate multiple graph instances with varying parameters and store them in a structured way.

```
./generators/generate.sh -n 3 -o datasets/planar_weighted_medium -- -planar 25 40 1 -random 1 10 42
```

## Running Graph Visualizer

Graph Visualizer is a Streamlit application that allows you to visualize the graph instances and the solutions generated by the algorithms. To run the visualizer, use the following command:

```
uv run streamlit run app.py --server.headless true --server.port 8504
```
